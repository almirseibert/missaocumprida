Para rodar o projeto

cd backend
npm install
cp .env.example .env
# Editar .env com seu PostgreSQL e defina ADMIN_PASSWORD (senha do admin do seed)
npx prisma migrate dev --name init
npm run db:seed
npm run dev

Frontend web:  cd frontend && npm install && npm run dev  (defina NEXT_PUBLIC_API_URL no .env.local)
Mobile:        cd mobile && npm install && npx expo start  (defina EXPO_PUBLIC_API_URL no .env com o IP da máquina)
